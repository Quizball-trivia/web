These files are the approved, repeatable keyword sets for QuizBall's international SEO campaign.

The obsolete Greece/Greek targets were intentionally retired on 2026-08-30. The active tracking set is UK, Georgia, Spain, Mexico, Argentina, Colombia, Chile and Brazil.

The keyword sets mix high-level category terms, intent-specific formats and current QuizBall topic clusters. `quizball` is included only as a branded baseline; weekly reporting should separate it from non-brand terms.

## Tags to apply after import

- `core`: football quiz/trivia category terms
- `format`: Career Path, Club Badges, guess-the-player and multiplayer intent
- `club`: club-specific quiz intent
- `brand`: QuizBall only
- `uk`, `georgia`, `spain`, `mexico`, `argentina`, `colombia`, `chile`, or `brazil`: market tag

The Georgian Semrush keyword database is sparse and currently reports zero volume for most Georgian-language terms. Keep those terms for position monitoring, but use Google Search Console impressions and clicks as the authority for demand. Brazil is intentionally Portuguese; do not use Spanish pages or Spanish keyword groups as a substitute for a future Portuguese launch.

## On Page SEO Checker

Do not target the product homepage (`/en`) with the generic football-quiz terms. Use the purpose-built hubs and format pages:

- `/en/football-quiz`: football quiz, football trivia, football quiz questions
- `/en/football-quiz/guess-the-player`: guess the player, guess the football player
- `/en/football-quiz/club-badges`: football badge quiz, football club badges quiz
- `/en/football-quiz/career-path`: football career path quiz, guess the career path
- `/es/quiz-de-futbol`: quiz de fútbol, trivia de fútbol, preguntas de fútbol
- `/es/quiz-de-futbol/adivina-el-jugador`: adivina el jugador, adivina el futbolista
- `/es/quiz-de-futbol/escudos-de-futbol`: escudos de fútbol, quiz de escudos de fútbol

The On Page SEO Checker location and language must match the URL group being evaluated. Never use the current Istanbul/Turkish target for English or Spanish recommendations.

Review after four complete weeks. Keep keywords that gain impressions or move into positions 4–40. Replace terms with no impressions only after checking Search Console wording and whether QuizBall has a genuinely relevant landing page.
